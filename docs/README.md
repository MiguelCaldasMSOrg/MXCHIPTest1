# Offline documentation mirrors

These are complete local snapshots retained for later reference. The original
mirrored files, including their cached images, scripts, stylesheets, and fonts,
are kept unchanged. They are reference material, not part of the firmware build
and not a separately maintained documentation distribution.

## Entry points

| Snapshot | Local entry point | Original source |
| --- | --- | --- |
| Microsoft Azure IoT DevKit documentation | [Home](Azure-IoT-DevKit/index.html) | [IoT DevKit](https://microsoft.github.io/azure-iot-developer-kit/) |
| Zephyr MXCHIP board documentation | [AZ3166 board](MXCHIP/boards/mxchip/az3166_iotdevkit/doc/index.html) | [Zephyr AZ3166 documentation](https://docs.zephyrproject.org/latest/boards/mxchip/az3166_iotdevkit/doc/index.html) |
| Zephyr MXCHIP board index | [Board index](MXCHIP/boards/mxchip/index.html) | [Zephyr MXCHIP boards](https://docs.zephyrproject.org/latest/boards/mxchip/index.html) |

Clone or download the repository and open the local HTML entry points in a
browser. GitHub's file viewer displays HTML source rather than running the
mirrored site. Some search features and links still use their original online
services. Snapshot content may describe different SDK or software versions
from this project's current configuration.
